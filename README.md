# Steady-the-Line
A 2D, top-down strategy game focusing on real troop behavior, following time-appropriate drill manuals as well as simulating realistic combat, morale and command structures.

## AI Notice
All art, music, design, and concept are human-made.
AI is only used as an advisory tool:
* for learning the programming language and general concepts
* to help with research as a "smart lookup" (Details are fact-checked manually)
* to identify bugs and recommend possible optimization
* for proofreading (mostly spelling, grammar and finding the right words)

Any AI-generated content will be clearly marked as such.

Contributors are expected to follow the same rules.

### Rationale
I believe that AI has no right to be in art, hence why all assets, music, design, etc., are human-made.
However, it is an extremely helpful and powerful tool and I think condemning all use of it is just as reckless as using it for everything.
Hence I decided to use it as an advisory tool to help me learn and grow, but not directly use its generated content. It's incredibly good for finding mistakes, things I overlooked, typos and the like.
