# Contributing to Steady the Line

Thanks for your interest in helping!
This is a solo project. The reason for it being public is to get feedback.

## Suggestions and bug-reports

Issues are the easiest way to contribute, and no agreement is needed for them.

When reporting a bug:
- state what you expected to happen vs what actually happened
- steps to reproduce
- screenshots and error message

Ideas for features, optimizations or historical corrections are all welcome.
If you're pointing out historical inaccuracies, a source helps a lot.

## Pull Requests
Pull requests are welcome, but keep in mind:
- For anything bigger than a minor bug-fix, open an issue first to discuss it, so you dont waste time coding something that cant be included.
- a PR should be focused on one change
- There is no obligation for your PR to be merged
